@startuml
title Huaqing Pool AI Companion Matching - Detailed Subsystem Design

actor User
participant "MatchingController" as Controller <<Controller>>
participant "ProfileBuilder" as Profiler <<Service>>
participant "MatchingEngine" as Engine <<Algorithm>>
participant "UserQuestionaryDatabase" as QDB <<Database>>
participant "ImperialConcubineDatabase" as ICDB <<Database>>

== Request & Questionnaire Phase ==
User -> Controller: MatchRequest(UserID)
activate Controller

Controller -> QDB: ObtainQuestionaryInformation()
activate QDB
QDB --> Controller: ReturnQuestionaryInformation(QuestionnaireData)
deactivate QDB

Controller --> User: ProvideQuestionnaire(QuestionnaireData)
deactivate Controller

User -> Controller: SubmitAnswers(AnswersLocation)
activate Controller

== Profiling Phase ==
Controller -> Profiler: ProcessAnswers(Answers)
activate Profiler
Profiler -> Profiler: BuildUserProfile(Interests, Personality, Needs)
Profiler --> Controller: UserProfile
deactivate Profiler

== Candidate Retrieval Phase ==
Controller -> ICDB: GetAIPartnerInformation(UserProfileFilter)
activate ICDB
ICDB --> Controller: ReturnAIPartnerInformation(CandidateList)
deactivate ICDB

== Matching Phase ==
Controller -> Engine: ExecuteMatchingAlgorithm(UserProfile, CandidateList)
activate Engine
Engine -> Engine: CalculateCompatibilityScores()
Engine --> Controller: MatchingResult
deactivate Engine

== Result Delivery ==
Controller --> User: ReturnMatchingReport(MatchingResult)
deactivate Controller

@enduml
