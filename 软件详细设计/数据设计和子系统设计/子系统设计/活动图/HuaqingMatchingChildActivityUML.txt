@startuml
title Activity Diagram - Execute Matching Algorithm (Sub-Activity)

|MatchingEngine|
start
:Receive User Profile & Candidate List;

if (Is Candidate List Empty?) then ([No])
    :Initialize Individual Scores;
    
    ' Concurrent execution of matching dimensions
    fork
        :Compute Interest Compatibility Score;
    fork again
        :Compute Personality Compatibility Score;
    fork again
        :Compute Emotional Needs Compatibility Score;
    end fork
    
    :Aggregate Compatibility Scores;
    :Sort Candidates by Total Score Descending;
    :Select Top Matches;
else ([Yes])
    :Set Empty Matching Result;
endif

:Return Final Matching Result;
stop
@enduml
